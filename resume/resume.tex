% --- BULLET SPACING FIX ---------------------------------------------------
% \small is now declared ONCE for the whole list, before the first \item -
% the same pattern the Summary section already uses. Previously \small was
% applied per item AFTER \item, and every item ended with \vspace{-2pt}.
% A \vspace at the end of a paragraph inside a list item is emitted
% inconsistently by TeX: it can be absorbed into \parsep, or applied after
% the paragraph, depending on whether another \item or \end{itemize}
% follows. That is what made the gaps between bullets look uneven.
% All bullet spacing is now set in ONE place, in \resumeItemListStart below.
% To change density, adjust itemsep ONLY - do not re-add per-item \vspace.
